# Study MBBS Abroad - Responsive Landing Page

## Overview
This is a responsive landing page for "Study MBBS Abroad" designed as part of the Front-End Development Intern application for **University Insights**. The page provides details about studying MBBS abroad, including country listings, program benefits, admission processes, and a lead generation form.

## Features
- **Hero Section**: A visually appealing banner with a CTA button.
- **Why Study MBBS Abroad**: Key benefits section.
- **Top Countries**: List of countries with brief details and images.
- **Admission Process & Eligibility**: Step-by-step guide for applicants.
- **Lead Generation Form**: Users can submit their name, email, phone, and preferred country.
- **Animations**: Smooth fade-in effects for better user experience.
- **SEO Optimization**: Proper headings and metadata included.
- **Tracking Integration**: Google Analytics and Facebook Pixel for performance monitoring.

## Technologies Used
- **HTML5**
- **CSS3 (Bootstrap 5.3)**
- **JavaScript**
- **Google Fonts (Poppins)**
- **Font Awesome Icons**

## Setup & Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/study-mbbs-abroad.git
   ```
2. Navigate to the project folder:
   ```bash
   cd study-mbbs-abroad
   ```
3. Open `index.html` in a browser.
4. (Optional) Deploy the site using Netlify or Vercel for a live demo.
